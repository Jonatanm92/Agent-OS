## 2. The service

Deadline Ledger is a schedule change-control application for monday.com.

The current product may:

- read Date and Timeline changes from a board Activity Log
- show old → new schedule values, actor and timestamp
- count repeated deadline moves
- identify changes without a recorded explanation
- let authorized users save/edit a reason and optional category for a specific change event
- maintain reason attribution/timestamp/revision metadata
- provide governance metrics, filters and search

The exact features included in a purchased plan are those described in the then-current Marketplace listing/pricing plan.
