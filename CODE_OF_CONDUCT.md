# Code of Conduct

Agent OS aims to be a practical, technically focused open-source project.

Contributors and maintainers are expected to:

- discuss ideas and code on their technical merits
- give actionable, specific feedback
- avoid harassment, threats, discriminatory abuse, and personal attacks
- respect privacy and do not publish another person's private information
- assume good faith while still being clear about bugs, risks, and disagreements
- keep project spaces useful for contributors and users

Maintainers may edit, hide, or remove content that violates these expectations,
and may restrict participation when necessary to protect the project community.

For conduct concerns that should not be handled publicly, contact the repository
maintainer through GitHub rather than opening a public issue.
